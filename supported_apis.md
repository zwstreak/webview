# Supported HTML Tags
* html
* head
* body
* div
* p, h1, h2, h3, h4, h5, h6
* button
* script
* title

# Supported JS API
## Hooks
### Global
* setTimeout

### Console
* log
* warn
* error

### Document
* getElementById
* getElementsByTagName
* getElementsByClassName

### Window
* document

## Bindings
### Element
* innerHTML
* children

### HTMLCollection
**LIVE** changes aren't currently supported.
* length
* item
* namedItem

# Supported CSS Selectors
CSS support does not exist yet.
