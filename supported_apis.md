# Supported HTML Tags
* html
* head
* body
* div
* p, h1, h2, h3, h4, h5, h6
* button
* script
* title

# Supported JS API
## Global
* setTimeout

## Console
* log
* warn
* err

## Document
* getElementById
* getElementsByTagName
* getElementsByClassName

## HTMLCollection
**LIVE** changes aren't currently supported.
* length
* item
* namedItem

# Supported CSS Selectors
CSS support doesn't exist yet.
