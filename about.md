# Webview
Webview support for Geometry Dash.

# Note
This mod is intended to be used by <cr>developers</cr>, And it does not do anything by its own.

# Settings
* You can turn off <cy>JavaScript Execution</cy> under the mod settings.
* You can turn off <cr>Warning Prompts</cr> under the mod settings.

# What does it do
It allows developers to render websites on Geometry Dash and returns a <cg>ZWebview</cg>* object.

# How to use?
Refer to the [GitHub Page](https://github.com/zwstreak/webview) For more information.
